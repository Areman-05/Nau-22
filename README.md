# Nau 22

Galería de exposiciones contemporáneas en Poblenou (Barcelona). El diseño de referencia vive en Figma Make; este repo es el front en Next.js y el contenido (artistas, colaboradores, programa).

No hay venta online.

## Desarrollo

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000)

## Rutas

- `/` — Home (carrusel de exposiciones)
- `/programa` · `/programa/[id]`
- `/artistas` · `/artistas/[id]`
- `/colaboradores/[id]`
- `/info` — visita
- `/miembros` — en desarrollo
